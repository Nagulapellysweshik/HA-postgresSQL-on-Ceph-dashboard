# Steps 03–04, stage and private EKS cluster: debugging

## Blockers hit

### B1. eksctl rejected `vpc.clusterEndpoints` with `privateCluster`
- **Symptom:** `vpc.clusterEndpoints cannot be set for a fully-private cluster`.
- **Fix:** removed the field. `privateCluster.enabled` controls the endpoints.

### B2. The dry run showed `nat: Single`
- **Root cause:** eksctl's default NAT is `Single`, even for a cluster meant to have no egress. It would also have needed an Elastic IP.
- **Diagnosis:** `eksctl create cluster -f cluster.yaml --dry-run | grep -A2 nat`.
- **Fix:** `vpc.nat.gateway: Disable`. Verified afterwards in the CloudFormation templates: no IGW, NAT or EIP (`cloudformation/`).

### B3. "Private" cluster is public during creation
- **Symptom:** the endpoint was public while eksctl ran.
- **Lesson:** verify with `aws eks describe-cluster --query cluster.resourcesVpcConfig` instead of assuming.
